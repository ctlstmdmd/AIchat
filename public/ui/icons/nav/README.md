# QQ Companion navigation assets

Visual direction: **黄白风**（奶油黄 + 奶白 + 暖棕描边 + 轻贴纸感）。

## Assets

- `message.svg` — 消息 / 切换聊天
- `contacts.svg` — 联系人
- `zone.svg` — QQ 空间 / 动态
- `channel.svg` — 频道 / 社群
- `call.svg` — 通话
- `settings.svg` — 设置

## Usage rules

- Transparent background.
- Prefer display sizes around 24–40px in navigation.
- Selected state: pale yellow glass pill behind the icon.
- Unselected state: no heavy background, keep the warm-brown outline visible.
- Do not mix these with unrelated blue/purple system icons.
- Text labels remain HTML/CSS text; do not rasterize labels into images.

Generated PNG concept art can later replace these SVGs one-for-one without changing component paths semantically.
